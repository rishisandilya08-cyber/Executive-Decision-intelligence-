◈ Executive Decision Intelligence

KPI → Revenue driver analysis · AI insight agent · What-if simulator · Assumed data (24 months, Nov ’24 – Oct ’26)

What the problem is saying

1
Too many KPIs. Marketing, sales, product and finance each send hundreds of indicators (traffic, CAC, open rate, NPS…).
2
No link to money. Leaders can’t tell which KPIs actually explain revenue and profit movement, and which are vanity metrics.
3
The ask. Build an LLM-powered system that connects operational KPIs to financial outcomes and writes evidence-based insights executives can act on.
4
Your role as analyst. Build the data layer + statistical drivers, then let an AI agent narrate, answer questions, and simulate decisions.

Solution architecture

Data layer – KPIs from CRM, ads, web analytics, finance → one monthly table.
Analytics engine – correlation, ridge regression (driver importance), month-over-month variance attribution.
LLM agent – receives the computed numbers as evidence and writes the explanation (grounded, no guessing).
Decision layer – what-if simulator + prioritized recommendations.

This demo’s agent is rule-based on the same computed evidence. In production, send the evidence JSON to an LLM API to phrase the answers.
